Design pattern legend

  • Repository (skillRepository, diagnosticRepository, etc.) — only layer that talks to Supabase directly.
  • Adapter (IContentGenerator, ITextToSpeech) — only layer that talks to Gemini/Google TTS; swappable later without touching app logic.
  • Decorator (TTS Cache) — checks Supabase Storage before ever calling the real TTS API, stretching the free tier.
  • Strategy (inside Diagnostic Engine) — the "what question comes next" logic is isolated so it can start rule-based and get smarter later.
  • Event-driven (Event Bus) — one "activity completed" event fans out to mastery update, dashboard refresh, and badge checks independently.

Dashed items (Razorpay, offline batch pre-generation) are Phase 2 — shown as seams, not built yet.
